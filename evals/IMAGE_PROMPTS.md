# Image series prompting notes

Regenerated using common practitioner rules from Midjourney / Flux / Runway guides:

1. **Shot grammar first** — camera + subject doing one action + place + light  
2. **One idea per frame** — no thesis paragraphs drawn as typography  
3. **Story in the picture** — captions live in `ARTICLE.md`, not inside the PNG  
4. **Negative space** — room for a headline in layout, not a wall of labels  
5. **Same grade across the set** — warm tungsten vs cool glass-blue, 16:9, editorial photo  
6. **Reference chaining** — later frames reuse the hero as a style lock  

Avoid: dense infographic text, split-panel caption walls, purple neon, logo brands.
